Origin IP Discovery & Bypass

High Risk

Cloudways hosting (`secure.cloudways.cloud`) creates potential avenues for origin server IP exposure. If the origin server does not strictly enforce Authenticated Origin Pulls (AOP) or restrict incoming firewall rules solely to Cloudflare IP ranges, attackers can bypass WAF protections entirely.

WordPress Admin Portal Exposure

Medium Risk

Public access to `/wp-login.php` combined with discovered usernames (e.g., author profile `bonnie`) enables automated brute-force attacks and targeted credential stuffing. Lack of IP-restricted access or zero-trust gateway protection leaves authentication dependent solely on application password policies.

Bulk Mail & API Hijacking Risk

Medium Risk

The inclusion of Amazon SES (`amazonses.com`) and SparkPost (`sparkpostmail.com`) in DNS TXT/SPF records authorizes third-party bulk distribution engines. Compromise of local developer credentials or API tokens could allow adversaries to hijack firm sending domain reputation for spear-phishing.
